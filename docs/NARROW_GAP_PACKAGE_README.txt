利用者の判断で2026-10-28に採用した補修を適用した確認用データです。公式境界・所属は未確定で、final_usable=falseです。
原典N03は保持し、市町村の所属が確認できる根拠付きパッチだけを市町村の派生版へ追加します。
指定がなければ市町村形状は変更しません。同一区域内の細い隙間は計画区で補修し、
広域流域は補修済み計画区から作ります。原典近くでの座標精度統一は、この処理には含みません。

市町村版ZIPは1911地物の派生市町村データです。
計画区・流域版ZIPには158計画区、44広域流域、未割当20地物、補修候補台帳、残る閉じた穴の一覧を収録します。
残る穴や近接は実在の水域等も含み、すべてを不具合とは扱いません。
補修幅・採否件数・独立検査はgap_validation.jsonと別添review_manifest.jsonを確認してください。
距離・面積は局所近似による値です。補修幅は全国の欠陥を解消する確定値ではありません。

GEOS妥当性や近接探索は、ArcGIS ProのEsri方式Check Geometryの代替ではなく、Esri合格を意味しません。
公開にあたっては、QGISでの全国検証と実機での表示確認を行います。
