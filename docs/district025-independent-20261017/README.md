## 添付JSONの実測結果

[機械可読結果](result.json)と[検査スクリプト](../../scripts/audit_district025_json.py)を保存しました。
保存用に入力・出力を引数化したスクリプトで再実行し、このセッションの最初の検査JSONと全項目一致を確認しています。

- 全体はMultiPolygon、`is_valid=true`、`Valid Geometry`。無効リングは0です。
- 2,384リングはすべて閉じた時計回りの外周で、穴は0です。
- 保存座標119,257個から重複閉点2,384個を除き、116,873頂点を検索しました。
- 正の距離が9e-9度以内の非隣接頂点の組は全体で1組です。別リング間は0組です。

リング・頂点番号は原JSON `features[0].geometry.rings[ring][pos]` の**0始まり**です。

| ring | pos | 経度 | 緯度 |
|---:|---:|---:|---:|
| 2023 | 54178 | 139.96788627800004 | 39.87999968500003 |
| 2023 | 54180 | 139.9678862720001 | 39.879999690000034 |

JSONの数値はPythonの倍精度浮動小数点で読み、その値から距離を計算しました。
Claude報告のShapely 2.2.0／GEOS 3.14.1による同一ハッシュのJSONの結果（有効・近接1組・同じ位置・約7.81e-9度）と一致します。

検索では閉点を除き、同一リングの連続する頂点と巡回隣接（始点と最後の非重複頂点）を除外しました。
異なるリング間も検索し、距離0と正の距離を区別しています。形状有効性の検査には閉点を保持しました。
これはGEOSの有効性と座標間距離の検証であり、ArcGISのXY許容値・分解能・クラスタリング判定を再現していません。
ArcGISで「未変更版」と「2頂点削除候補」を同じ条件で比較した結果は、まだ確認できていません。
