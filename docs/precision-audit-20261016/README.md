## 再実行

元入力ZIPを各Releaseから取得し、上記ハッシュと照合して展開する。依存パッケージは隔離環境へ導入する。

```bash
python -m venv .audit-env
.audit-env/bin/python -m pip install shapely==2.1.2 numpy==2.5.4 scipy==1.18.1 pyproj==3.8.0
.audit-env/bin/python scripts/audit_close_vertices.py expanded_precision_trial.gpkg --output trial-result.json
.audit-env/bin/python scripts/audit_close_vertices.py forest_planning_zones_2026_provisional_labeled.gpkg --output national-result.json
.audit-env/bin/python scripts/audit_notch_candidate.py expanded_precision_trial.gpkg forest_planning_zones_2026_provisional_labeled.gpkg --output notch-result.json
```

別環境へShapely 2.2.0を導入して同じコマンドを実行すれば版比較できる。Windowsでは`.audit-env/bin/python`を`.audit-env/Scripts/python.exe`へ読み替える。出力先が既存の場合は上書きを拒否する。
