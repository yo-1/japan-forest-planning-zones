# 境界資料の検証（2026-10-05）

対象は行政上の森林計画区158・広域流域44の区域全体。森林計画対象森林のポリゴンは森林の所在を示し、計画区域の境界とは異なる。

## 資料

- [林野庁・全国森林計画](https://www.rinya.maff.go.jp/j/keikaku/sinrin_keikaku/con_3.html)（令和8年6月変更）の44広域流域名と候補表を全件照合し、名称差は0件。連番01～44の公式コード性は未確認。
- [広域流域位置図](https://www.rinya.maff.go.jp/j/keikaku/sinrin_keikaku/attach/pdf/con_3-2.pdf)は概略位置を示すPDFであり、測地座標のある精密な境界線ではない。
- [森林計画対象森林レイヤ](https://www.geospatial.jp/ckan/dataset/layer)の[データ定義書（2026年3月23日）](https://www.geospatial.jp/ckan/dataset/aa0bc6ed-f5ac-4f05-89c6-0c7034503303/resource/5e031fcf-ed9a-4594-892a-4129feccea0c/download/data_dictionary_20260323.pdf)別紙1は全国コード001～158を列記し、候補表のコード・名称と158件すべて一致。別に那須御用林の701も記載。森林側の形状は計画区全域に読み替えない。
- [国土数値情報・森林地域A13](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-A13.html)には計画区・広域流域の区域識別子がない。
- 利用者提供の2026年8月19日付企画提案書本文11頁は、利用可能な森林計画区GISが公開されていないとして、計画図・自治体界・主要河川を組み合わせる作成法を提案する。事業者の評価であり公式境界の保証ではない。

## 照会事項

林野庁に、(1)158計画区と44広域流域の**区域全体**のGIS、基準日、利用条件の有無、(2)定義書の全国コードと北海道GeoPackageの別体系、2桁・3桁の併存、特別コード701、(3)幌延町、新島村、札幌市の扱い、(4)市町村内の分割と島しょ部の境界資料を確認する。回答までコードを機械的にゼロ埋め変換せず、候補表の値を確定値に上書きしない。
