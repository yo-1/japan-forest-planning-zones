## 実装・自動検証

mainのArcGIS向けMULTIPOLYGON宣言と独立精度監査を補修ブランチへ取り込みました。
通常の配布ビルドはv0.3互換の処理を維持し、補修は`--gap-width-m`で明示した試験に限ります。
試験ZIPには専用READMEを付け、通常版とはZIP名を分けます。

独立検証では、追加・減少領域、補修台帳、他区域との重複、流域の再集約一致に加えて、
未割当20地物の識別子・コード・座標、計画区から流域への所属、名称・原典件数、
`final_usable=false`を検査します。CIでは158計画区・44流域・未割当の近接探索結果も保存します。
近接探索は読み取り専用で、Esri検査の合否を推定しません。

公開ワークフローは手動実行・新しいタグのみとし、既存Release・タグ・添付や過去の成果物を削除しません。
未採用の補修試験を公開ワークフローから既定実行しません。

ローカルの単体検査は99件中93成功・6未実行・失敗0です。未実行6件はN03_DBF未指定の原典属性照合です。
構文検査と対応表・表示設定の監査も成功しました。通常ビルドを全国再生成し、公開v0.3の全222地物について、全属性・図形バイナリの完全一致を確認しました。
[比較結果](gap-audit-20261017/v03-compatibility.json)を保存しています。補修試験の全国再生成結果は完了後に追記します。
Windows CIで試験用SQLite接続の解放不足による一時ファイル削除エラーを検出し、接続を明示して閉じるよう修正しました。

ArcGIS実機検査の補助スクリプトと[実行手順](ARCGIS_GAP_CHECK.md)を準備しました。ArcPy実行は未確認です。
