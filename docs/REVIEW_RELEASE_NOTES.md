# 確認用データ v0.2

森林計画区・広域流域の**暫定候補データ**です。行政上の森林計画区・広域流域の候補図で、公式境界又は自然河川流域を示す確定データではありません。

- `forest_planning_zones_2026_review.zip`：色・番号・名称ラベル付き158計画区、44広域流域、未割当20地物、19座標系区域（[japan-plane-rectangular-cs-zones v2026.2](https://github.com/yo-1/japan-plane-rectangular-cs-zones/releases/tag/v2026.2)）、対応CSV。
- `municipality_forest_zones_2026_candidate.zip`：結合前の分割を保持した市町村候補レイヤ。1,911地物、1,905コード。
- `review_manifest.json`：件数、形状・SQLite検査、元座標系区域との形状一致。
- `SHA256SUMS.txt`：ダウンロードZIPのSHA-256。


QGISで座標系区域を最上位に置き、計画区図と広域流域図の面レイヤを切り替えます。座標系の形状は v2026.2 のZIPのSHA-256と形状ハッシュを照合し、一致したものだけを使います。赤いローマ数字の`layer`スタイルを初期表示とし、元の`default`スタイルも保持します。

v0.1 からの違いは、計画区・広域流域のレイヤで、面積1平方メートル未満の小さな穴（内側のリング）を取り除いたことです。市区町村の境界を合わせたときにできたもので、外側の輪郭は変わりません。取り除いた数と面積は`review_manifest.json`の`tiny_interior_rings_removed`にあります。1平方メートル以上の穴（元データの市区町村そのものがもつ穴、9件）は残しています。

全域・一部指定や島しょ部は未確定。全件の最終利用可否はfalseを維持しています。機械検査の合格は公式境界の確定を意味しません。QGIS実画面での表示は未確認です。
