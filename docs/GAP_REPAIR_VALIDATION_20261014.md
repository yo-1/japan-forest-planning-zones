# 森林計画区・広域流域の細い隙間補修（2026-10-14）

N03由来の市町村入力を保持し、同じ森林計画区内の隙間を補修しました。今回は市町村の所属を確定する修正パッチを指定していません。

全国158計画区、44広域流域、未割当20地物を保持しています。補修パッチは1,568件、残る閉じた穴は16件です。残る穴には水域等も含むため、すべてを不具合とは扱いません。

## 検査結果

- ローカルテスト：90件中84件成功、6件未実行（N03_DBF未指定）、失敗0。
- GDAL 3.12.4で5図形レイヤを正常に読みました。
- 44流域すべてで、補修済み計画区の再集約結果との正規化座標一致を確認しました。
- 新たな重複、不正形状、台帳にない追加は、検査基準を超えて検出されませんでした。
- 差分演算による追加面積の局所換算合計：0.0206088874549㎡。
- 減少側の数値残差の合計：6.91703108473e-08㎡。計画区あたり0.0001㎡以下を数値誤差として扱う基準内です。
