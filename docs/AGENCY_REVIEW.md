# 林野庁・都道府県向け 現物確認の入口

作成日：2026-10-05／対象：確認用v0.1。依頼送信・回答受領は未実施です。

本プロジェクトは、全国森林計画の44広域流域と地域森林計画の158森林計画区について、市町村界を基礎とした候補ポリゴンと対応表を作成したものです。自然河川流域の解析による区画ではなく、森林計画の行政上の区画の候補です。**公式の所属・境界は未確定です。**

## 現物の入手

1. [ダウンロード用Releases](https://github.com/yo-1/japan-forest-planning-zones/releases)の確認用`review-v0.1-20261005`を開きます。
2. `forest_planning_zones_2026_review.zip`を取得・展開します。158計画区・44広域流域・未割当20地物のGeoPackage、19座標系のGeoPackage、対応CSV、QGISスタイルが入ります。
3. 市町村単位で追跡する場合は、`municipality_forest_zones_2026_candidate.zip`も取得します。1,911地物・1,905コードで、座標系ごとの元分割を保持しています。
4. `SHA256SUMS.txt`でZIPの同一性を確認します。[QGIS表示手順](QGIS_REVIEW.md)に従い、座標系境界を上に置いて計画区図・広域流域図を切り替えます。

Releaseがまだ一覧に現れない場合は[公開処理の実行状況](https://github.com/yo-1/japan-forest-planning-zones/actions/workflows/publish-review.yml)を確認してください。公開完了前のURLを「ダウンロード可能」とは扱いません。従来の分割データ入手方法は[PROVISIONAL_GPKG.md](PROVISIONAL_GPKG.md)に残しています。

## 確認済みの範囲

- 市区町村コード1,905と元ポリゴン1,911地物の対応を内部照合。5自治体は座標系ごとに複数地物があり、地物単位では1対1ではありません。
- 暫定集約は158計画区・44広域流域・未割当20地物。形状検査で無効・空形状0、EPSG:6668、SQLite整合性ok。これは技術的妥当性の検査です。
- 北海道・東京・鹿児島・沖縄の森林計画対象森林54,493地物から、候補の291コードに対応する属性を照合。残る1,614コードはこの4都道県による照合の対象外です。
- 291コードに森林が観測されたことは、市町村全域の所属又は行政上の境界を確認したことにはなりません。
- [4都道県の属性照合](../data/forest/forest_target_four_pref_comparison.csv)、[複数系の重なり検査](../data/forest/split_municipality_forest_evidence.csv)、[出典・境界資料の調査](BOUNDARY_SOURCE_REVIEW.md)を参照できます。

## 回答後の扱い

主CSV・ポリゴンを先に書き換えず、回答日・対象区域・根拠・適用日を記録します。市町村全域が一つの区域と確認できた場合は行政界を使用し、一部指定には公式境界に基づく分割を適用します。再集約後に欠落・重複・形状・所属・QGIS表示を検査し、確定範囲を区別して公開します。

コード・島しょ部の具体的な照会事項は[INQUIRY_STATUS.md](INQUIRY_STATUS.md)、現在の表と出典は[data/forest/README.md](../data/forest/README.md)を参照してください。
