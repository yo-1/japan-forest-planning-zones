2026-10-04  系と系の間の重なり・すき間、奄美群島の範囲、出典の書き方
----------------------------------------------------------------------

重なりとすき間（Claude Code の環境、Shapely 2.1.2）
  - リリース v2026.1 の plane_rectangular_zones_2026.gpkg（19系、頂点 10,628,256個）を使った。
  - 19個のジオメトリはすべて有効（is_valid）。
  - 接している系の組み合わせは12組（I-II、III-IV、III-V、IV-V、V-VI、VI-VII、VII-VIII、VIII-IX、VIII-X、IX-X、XI-XII、XII-XIII）。
  - 重なり：10組は境界線だけで接していて、重なりの面積は0。I-II と III-V は、ごく小さな面のかけらが出たが、
    面積は合計で 7.6e-16 平方度・4.0e-15 平方度（およそ 0.00001 平方メートル・0.00004 平方メートル）で、
    計算の誤差の大きさ。意味のある重なりはない。
  - すき間：19系をすべて合わせた形の中の穴は19個。そのうち、2つ以上の系に囲まれた穴（系と系の間のすき間）は4個で、
    どれも VIII系（長野県）と IX系（群馬県）の境、東経138.55〜138.64度・北緯36.417度付近にある。
    面積は最大 4.6e-13 平方度（およそ 0.005 平方メートル）で、実用上は問題にならない。
    ディゾルブはすき間を作らないので、元データの長野県と群馬県の境界線がわずかに食い違っていると推定（元データでは未確認）。
  - 残りの15個の穴は1つの系の中にあり、元データにもともとある穴と考えている（各系の中の穴は合計302個）。

奄美群島の範囲（「大島郡と奄美市」とみなす仮定）
  - Web 検索の結果の要約では、奄美群島振興開発特別措置法の奄美群島は「奄美市及び鹿児島県大島郡の区域」とされていた
    （以前は名瀬市及び大島郡）。仮定と合っている。
  - Claude Code の環境からは e-Gov 法令検索・衆議院のサイトに接続できず、条文の原文は確かめていない（未確認）。

2026-10-04  既存レイヤとのポリゴン数の食い違い（1,771件）の原因
----------------------------------------------------------------------

食い違いの内容（以前の比較）
  - ユーザーの PC にある既存レイヤ heichoku_kei_zone_extents_grouped_2026 の source_fragment_count は合計123,359件で、
    こちらの集計（元データ N03-20260101 の125,130件）より1,771件少ない。
  - XI〜XIX系は一致。I〜X系だけが少ない（I系15件、II系185件、III系84件、IV系92件、V系100件、VI系297件、
    VII系156件、VIII系201件、IX系420件、X系221件）。

確かめたこと（Claude Code の環境）
  - ユーザーから受け取った N03-20260101_prefecture.dbf
    （SHA-256 77e40b62ee5fea1f15c2465c7dafd1799bcdc29022ebc9cd5af4151b3be8cfe6）を読んだ。
    123,025行、削除済みの行は0件。47都道府県。どの行も N03_002〜N03_005 は空で、N03_007 は都道府県コード＋000。
  - 北海道・東京都・鹿児島県・沖縄県以外の43府県について、府県ごとに
    「N03-20260101.dbf の行数 − N03-20260101_prefecture.dbf の行数」を求め、府県の系ごとに足した。
  - 結果は、上の I〜X系の差（15・185・84・92・100・297・156・201・420・221、合計1,771）と、10系すべてで一致した。

結論
  - 既存レイヤは、43府県には都道府県単位のファイル（N03-20260101_prefecture）を、
    北海道・東京都・鹿児島県・沖縄県には市区町村単位のファイル（N03-20260101）を使って作られたと判断した。
    系の割り当ての違いではない。
  - 都道府県単位のファイルの行が少ないのは、市区町村の境で接していたポリゴンが1つにまとまるためと推定（形は見ていない）。
  - 配布データ（v2026.1）は、どの単位でも N03-20260101 を元にしているので、変更は要らない。

2026-10-04  重なり・すき間のかけらの頂点を調べた結果
----------------------------------------------------------------------

使ったもの（Claude Code の環境、Shapely 2.1.2）
  - リリース v2026.1 から plane_rectangular_zones_2026.zip を取り直し、中の GeoPackage を使った。
  - かけらの位置：I-II は東経129.759〜129.796度・北緯33.255〜33.333度（長崎県と佐賀県の境）、
    III-V は東経133.198〜133.241度・北緯35.500〜35.549度（島根県と鳥取県の境）、
    VIII-IX のすき間4個は北緯36.4167度付近の東経138.553〜138.638度（長野県と群馬県の境）。

重なり（I-II、III-V）
  - かけらの頂点は、片方の系の頂点と、もう片方の系の頂点が対になっている。
    小数9桁に丸めると同じ値になるが、片方には 1e-14〜2e-13 度（10〜20ナノメートル程度）の端数が付いている。
    例：II系側 (129.76435000000004, 33.306394441000066)、I系側 (129.76435, 33.306394441)。
  - 端数が付いているのは、I-II では II系側、III-V では III系側。
    系全体でも、頂点の約5〜14%に小数9桁で表せない端数が付いている（50個おきに抜き出して数えた）。
  - 同じ県境の頂点が、ごくわずかに違う値になったため、交差の計算で細い面のかけらができたと判断した。
  - 端数が元データからあったのか、QGIS での処理（ディゾルブなど）で付いたのかは未確認
    （元データの .shp で同じ頂点の値を見れば確かめられる）。

すき間（VIII-IX）
  - 4個とも、北緯36度25分（36.41666…度。2次メッシュの区切りの緯度）の上の頂点でできている。
    長野県（VIII系）側は北緯 36.41666666850003度、群馬県（IX系）側は 36.416666669250105度で、
    約 1.2e-9 度（約0.1ミリメートル）ずれている。どちらの頂点も、もう片方の系にはない。
  - 一方、すぐ隣の 36.41666625200014度の頂点は両方の系にある（共通）。
  - 区切りの線の上の点を、県ごとに別々に計算したために、わずかに違う値になったと推定。
    ディゾルブは区切りの線の上に新しい点を作らないので、元データ（またはその作成過程）から来たと推定。
    元データの .shp では未確認。

実用上の影響
  - ずれは最大でも約0.1ミリメートルで、色分け・面積・系の判定には影響しない。配布データは直さない。
