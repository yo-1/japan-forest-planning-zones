# japan-plane-rectangular-cs-zones

日本の平面直角座標系（全国19系）の適用区域ポリゴンデータです。
国土数値情報（行政区域データ）の行政区域に平面直角座標系の系番号を付与し、系ごとにグループ化したポリゴンと、
都道府県・市町村と系番号の対応データを提供することを目的としています。

> **現状**: リポジトリの初期整備の段階です。データファイルと生成スクリプトはまだ含まれていません。

## 提供予定のデータ

| 種類 | 内容 |
|---|---|
| 対応データ | 都道府県・市町村（行政区域コード）と系番号（1〜19）の対応表 |
| ポリゴン | 系番号ごとにグループ化した適用区域ポリゴン |

ファイル形式・座標参照系・ディレクトリ構成は、データの追加時にこの README に記載します。

## データの出典と加工内容

| 項目 | 内容 |
|---|---|
| 出典 | 国土交通省「国土数値情報（行政区域データ）」2026年版 |
| 出典URL | https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html |
| 加工内容 | 平面直角座標系の系番号を付与し、系ごとにポリゴンをグループ化 |
| 適用区域の参照資料 | 国土地理院「わかりやすい平面直角座標系」 https://www.gsi.go.jp/sokuchikijun/jpc.html |

このリポジトリのデータは、国土交通省「国土数値情報（行政区域データ）」を加工して作成したものです。
国土交通省および国土地理院が作成・公開したものではありません。

### 注意事項

平面直角座標系の適用区域は、原則として都道府県・市町村の単位で定められていますが、
一部の島しょ部などでは経緯度による範囲で定められています。そのため、同じ市町村の中で系番号が
分かれる場合があり、市町村単位の対応表だけでは系番号を一意に決められないことがあります。
該当する区域の扱いは、データの追加時にこの README に記載します。

座標の測量・設計などに使う場合は、国土地理院の資料と根拠法令（座標系の告示）で適用区域を確認してください。
