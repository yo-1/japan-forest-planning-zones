# japan-plane-rectangular-cs-zones

日本の平面直角座標系（全国19系）の適用区域ポリゴンデータです。
国土数値情報（行政区域データ）の行政区域に平面直角座標系の系番号を付与し、系ごとにグループ化したポリゴンと、
都道府県・市町村と系番号の対応データを提供することを目的としています。

> **現状**: 19系の定義（`data/zones.csv`）と系番号の判定ルール（`data/zone_rules.csv`）を収録しています。
> 都道府県・市町村との対応データ、ポリゴン、生成スクリプトはまだ含まれていません。

## 収録データ

### `data/zones.csv` — 19系の定義

平面直角座標系（平成十四年国土交通省告示第九号）の表を転記したものです。文字コードは UTF-8（BOM なし）、改行は LF です。

| 列名 | 内容 |
|---|---|
| `zone` | 系番号（1〜19） |
| `zone_roman` | 系番号のローマ数字表記（I〜XIX） |
| `origin_lon_dms` / `origin_lat_dms` | 座標系原点の経度（東経）・緯度（北緯）。告示の値（度分秒） |
| `origin_lon` / `origin_lat` | 同じ値の10進数表記（度） |
| `epsg_jgd2011` | 対応する EPSG コード（JGD2011、EPSG:6669〜6687） |
| `area_text` | 告示の「適用区域」の文言 |

- 原点・適用区域は、国土地理院のページ「平面直角座標系（平成十四年国土交通省告示第九号）」
  https://www.gsi.go.jp/LAW/heimencho.html （最終改正 平成二十二年三月三十一日国土交通省告示第二百八十九号）から転記しました。
- `epsg_jgd2011` は告示には含まれません。原点の経緯度と縮尺係数 0.9999 が EPSG の定義と一致することを、
  pyproj の EPSG データベースで確認しています（`tests/test_zones_csv.py`）。
- `area_text` は人が読むための文言です。系番号の判定には `data/zone_rules.csv` を使います。

### `data/zone_rules.csv` — 系番号の判定ルール

告示の適用区域を、元データ（行政区域データ）の属性と経緯度で判定できる形に書き直したものです。
UTF-8（BOM なし）、改行は LF です。

| 列名 | 内容 |
|---|---|
| `rule_id` | ルールの番号。この昇順に評価し、最初に一致したルールを採用する |
| `zone` | 系番号 |
| `prefecture` | 都道府県名（N03_001 と照合） |
| `subprefecture` | 北海道の振興局名（N03_002 と照合） |
| `county` | 郡名（N03_003 と照合） |
| `municipality` | 市区町村名（N03_004 と照合） |
| `lon_min` / `lon_max` / `lat_min` / `lat_max` | 代表点の経度・緯度の範囲（度、JGD2011）。両端を含む |
| `basis` | 告示の該当箇所（要約） |
| `note` | 補足・仮定 |

- 空欄の条件は「指定なし」です。
- 「〜を除く」は評価順で表しています。例：東京都は XIV系・XVIII系・XIX系の範囲を先に評価し、
  どれにも当たらなければ IX系。
- 境界線ちょうどの点は複数のルールに当たりますが、`rule_id` の小さいルールが優先されます
  （例：東経143度ちょうどは XIV系）。
- 判定処理は `scripts/zone_rules.py`（標準ライブラリのみ）です。

**仮定・未確認事項**

- 経緯度の条件は、ポリゴンの代表点（ポリゴン内部の1点）で判定する前提です。1つのポリゴンが境界線
  （例：北緯28度、東経126度・130度）をまたぐ場合は判定できないため、生成時に検出する予定です。
  元データで島がポリゴンごとに分かれているかは未確認です。
- 鹿児島県の「奄美群島」は、大島郡と奄美市とみなしています（仮定）。
- 振興局名・市町村名・郡名の表記が元データの値と一致するか（例：「後志総合振興局」）は、
  元データで未確認です。

### 注意事項

平面直角座標系の適用区域は、多くは都道府県・市町村・振興局の単位で定められていますが、
次の都県では経緯度による範囲で定められています（告示より）。

| 都県 | 系 | 区分の基準 |
|---|---|---|
| 鹿児島県 | I・II | 北緯27〜32度、東経128度18分〜130度（奄美群島は130度13分まで）の範囲内の島しょは I系、それ以外は II系 |
| 東京都 | IX・XIV・XVIII・XIX | 北緯28度より南を東経140度30分と143度で区分。それ以外は IX系 |
| 沖縄県 | XV・XVI・XVII | 東経126度と130度で区分 |

これらの都県では同じ市町村の中で系番号が分かれる場合があり、市町村単位の対応表だけでは
系番号を一意に決められないことがあります。該当する区域の扱いは、データの追加時にこの README に記載します。

北海道は、振興局の所管区域と一部の市・町の単位で XI〜XIII系に分かれます。

座標の測量・設計などに使う場合は、国土地理院の資料と根拠法令（座標系の告示）で適用区域を確認してください。

### 元データについての注意（出典URLのページの「その他の情報」より）

- 一部の市区町村には境界が未確定の地域があり、元データでは境界線が暫定的に設定されています。
  このリポジトリのポリゴンもその暫定境界線を引き継ぎます。未確定地域の詳細は、該当する市区町村に確認してください。
- 東京都千代田区・中央区・港区の境界と、東京都中央防波堤埋立地は、元データの側で修正が行われています。

### 使用する元データの属性

元データ（行政区域データ 2026年版）の属性のうち、次を使用する予定です。属性名の括弧内はシェープファイルの属性名です。

| 属性名 | 用途 |
|---|---|
| 都道府県名（N03_001） | 系番号の付与 |
| 北海道の振興局名（N03_002） | 北海道内の系番号の付与 |
| 郡名（N03_003） | 表示用 |
| 市区町村名（N03_004） | 系番号の付与 |
| 政令指定都市の行政区名（N03_005） | 表示用 |
| 全国地方公共団体コード（N03_007） | 対応表のキー |

全国地方公共団体コードは、元データの定義で任意項目（多重度 0..1）です。コードが空のポリゴンの扱いは、
データの追加時にこの README に記載します。

## テスト

リポジトリのルートで実行します（Python 3.9 以降を想定。標準ライブラリのみで動きます）。

```bash
python -m unittest discover -s tests -v
```

pyproj がない環境では、EPSG の定義との照合テストはスキップされます（未実行として扱ってください）。

`tests/test_zone_rules.py` の地点ごとの期待値は、告示の適用区域から導いたものです。代表点の経緯度は
おおよその位置で、元データとの照合はしていません。
