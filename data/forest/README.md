# 市町村・森林計画区・広域流域 対応表 v0.1

作成日：2026-10-03（JST）／状態：確認用初版

## 現在の確認範囲

**この版は、全国の現行境界を確認し終えた確定版ではありません。**
行政区域のコードは2026年1月1日版N03の実データから取得しました。一方、全国の所属関係の基礎となった公式一覧は2010年2月1日現在です。資料の取得日や検索結果の表示日を、資料自体の基準日として扱っていません。

行政区域コード1,905件（政令市の行政区、所属未定地を含む）を収録しました。候補あり1,885件、そのうち所属森林計画区を県公式資料と名称照合したもの96件、2010年一覧の名称条件に一致したもの1,789件、未対応20件です。これは自治体数1,905という意味ではありません。

富山・宮城・鹿児島は県公式の区域一覧も使用しました。所属計画区を確認したことと、市町村全域を結合して正確な境界を再現できることは別です。全行の`coverage`は未確認、`usable_for_final_polygon`はfalseです。現在の広域流域との所属関係も全国一覧の時点から更新確認が必要です。

再生成例（UTF-8のN03 DBFを別途用意）：

```bash

```

## QGISでの確認用結合

1. CSVを「ジオメトリなしのテーブル」として読み込みます。コード列を文字列とし、自動数値変換を避けます。
2. 元の行政区域レイヤーの`N03_007`とCSVの`municipality_code`を結合します。
3. `verification_status`と出典を確認します。所属未定地、未対応行、境界が未確認の行は自動的に確定値として扱わないでください。
4. 市町村内で計画区が分かれる場合は、対応CSVに複数行を持たせるだけでは形状を再現できません。区域を特定する境界データでポリゴンを分割したうえで対応を持たせます。
5. 最終ポリゴンのdissolveは、現行資料と境界確認が終わった区域を対象に実施します。

## 列の意味

- `municipality_code`：N03_007の実値。所属未定地には県コード＋000が含まれます。
- `prefecture`,`subprefecture`,`county`,`municipality`,`ward`：N03_001～005の実値。
- `district_code`,`district_name`：森林計画区のコード・名称。未対応は空欄。
- `basin_code`,`basin_name`：基礎一覧で当該計画区が属する広域流域。未対応は空欄。
- `coverage`：市町村全域／一部の確認結果。本版は全件未確認。
- `match_method`,`matched_rule`：名称条件の照合方法と一致した条件。
- `verification_status`：所属計画区の照合状況。境界の確定を意味しません。
- 広域流域専用の確認状態列はv0.1にはありません。`verification_status`が県資料との照合を示す行でも、`basin_code`・`basin_name`の現行所属と島しょ部の境界は未確認です。
- `source_date`,`source_url`,`source_page`：市町村と計画区の所属に使った資料の時点・URL・PDFページ。
- `basin_source_date`,`basin_source_url`：計画区と広域流域の対応に使った資料。
- `n03_date`：行政区域データの基準日。`checked_date`：今回の照合日。
- `usable_for_final_polygon`：確定版生成に採用できるか。本版はfalse。

## 照合処理での扱い

都道府県を限定したうえで市名、郡名、郡内の列挙・除外条件を照合しました。北海道の同名の郡も、列挙・除外条件を保持しています。東京都特別区は多摩計画区の包括区域記載に対応させています。政令市の行政区はN03の市名で所属候補を求めます。

名称の表記差として塩竃市→塩竈市、駒ケ根市→駒ヶ根市、芦北郡→葦北郡を照合時に置換しました。全国一覧の原文は別表に保持しています。旧市町村の合併、市制施行、県内での計画区境界の変更は、この文字置換では解決していません。

本版で候補が一意であったことは、市町村内の分割が存在しない証拠ではありません。DEMの水文解析から境界を作成していません。対象森林だけの区域を、森林計画区全体の区域として扱っていません。

## 確定版に向けた残作業

未対応20件の所属を確認し、全国の現行計画区と広域流域の関係を点検します。2010年から市域が拡張・変更された市町村は名称一致だけでは不十分です。各都道府県の現行計画書・告示・境界データで市町村全域／一部を確認し、必要な分割境界を取得します。

GitHubへの実装対象は、data/内の対応CSV、scripts/内の付与・分割・集約処理、READMEと出典・利用条件の記載です。今回、既存リポジトリや元ポリゴンは変更していません。
